# Inventory Management System 📦

Интеллектуальная система управления складскими запасами. Проект демонстрирует навыки проектирования реляционных баз данных, реализации бизнес-логики на Python и создания надежных консольных интерфейсов.

## 🌟 Ключевые особенности
- **Реляционная архитектура:** Использование двух связанных таблиц (`inventory` и `categories`) через `category_id`.
- **Сложные SQL-запросы:** Реализованы `JOIN` отчеты для вывода полной информации о товаре вместе с его категорией.
- **Интерактивное меню:** Удобная навигация между добавлением товара, поиском и просмотром отчетов.
- **"Пуленепробиваемый" ввод:** Все числовые данные проходят валидацию через кастомные функции-обработчики. Программа защищена от вылетов при некорректном вводе.
- **Автоматизация категорий:** Система сама определяет, существует ли категория в базе, и автоматически создает её при необходимости.

## 📋 Функционал меню
1. **Поступление / Добавление:** Умное обновление остатков (если товар есть) или создание новой карточки товара.
2. **Поиск:** Мгновенное получение данных о цене и категории конкретного товара.
3. **Контроль дефицита:** Отдельный отчет по товарам, количество которых менее 5 единиц.
4. **Выход:** Корректное завершение сессии и закрытие соединения с БД.
