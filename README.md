# Inventory Management System 📦

Консольное приложение на Python для управления складскими запасами с использованием реляционной базы данных SQLite.

## 🚀 Основные возможности
- **Управление товарами:** Добавление новых позиций и автоматическое обновление количества существующих.
- **Реляционная база данных:** Использование связанных таблиц (Товары и Категории) через `FOREIGN KEY`.
- **Интеллектуальные отчеты:** Вывод информации с помощью SQL-запросов `JOIN` (товар + его категория).
- **Валидация данных:** Защита от ошибок ввода с помощью кастомных функций-обработчиков и блоков `try/except`.
- **Контроль остатков:** Мгновенный поиск товаров, количество которых на складе менее 5 единиц.

## 🛠 Технологии
- **Python 3.x**
- **SQLite3**
- **Git**

## 💻 Как запустить
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/bedstor/Inventory-Management-System.git
   ```
2. Запустите программу:
   ```bash
   python inventory_system.py
   ```

## 📈 Структура проекта
- `inventory_system.py` — основной файл с логикой и меню.
- `inventory_con.db` — файл базы данных SQLite (генерируется при первом запуске).
- `.gitignore` — исключение лишних файлов из репозитория.
