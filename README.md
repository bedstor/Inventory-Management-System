# Inventory Management System 📦

Профессиональная консольная система учета товаров с реляционной базой данных.

## 🚀 Основные возможности
- **Умное меню:** Управление программой через интерактивный выбор действий.
- **JOIN-отчеты:** Объединение таблиц товаров и категорий для наглядного вывода.
- **Валидация:** Защита от ошибок ввода (программа не вылетает при вводе букв вместо цифр).
- **Контроль остатков:** Автоматический мониторинг дефицитных товаров.

## 🛠 Технологии
- **Python 3.10+**
- **SQLite3**
- **Git** (Контроль версий)

## 📂 Структура проекта
- `inventory_control.py` — основной файл программы.
- `inventory_con.db` — база данных (игнорируется Git).
